## Featured Projects

### [Lichen Tracker](https://github.com/morgam7/lichen-tracker)

A full-stack Flask web application for recording and managing lichen sightings. The application uses a RESTful API and SQLite database to support create, read, update and delete operations, with a responsive frontend built using HTML, CSS and JavaScript. This project demonstrates my skills in Python, Flask, SQL, database design, API development and web deployment.

[View the hosted application](https://morgam7.pythonanywhere.com/)

### [Irish Wind Data Analysis](https://github.com/morgam7/irish-wind-data-analysis)

An analysis of historical wind-speed data from Met Éireann weather stations, exploring trends and their potential relevance to wind-energy development in Ireland. Using Python and Jupyter Notebook, I cleaned and combined weather datasets, created statistical visualisations and applied regression modelling. This project demonstrates my skills in pandas, NumPy, Matplotlib, Seaborn and scikit-learn, while connecting data analytics with environmental and renewable-energy applications.

### [Iris Dataset Analysis](https://github.com/morgam7/iris-dataset-analysis)

An exploratory analysis of the Iris flower dataset using Python and Jupyter Notebook. I used summary statistics, correlations, histograms, scatterplots, regression plots and heatmaps to compare flower measurements and investigate how petal and sepal characteristics differ among three Iris species. This project demonstrates my skills in pandas, Matplotlib, Seaborn, data visualisation and interpreting statistical relationships.
